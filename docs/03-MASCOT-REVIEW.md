## Codex 완료 1 — 마스코트 시안 3종 — 2026-11-20

제작: `public/brand/concepts/a.svg`, `b.svg`, `c.svg`, 비교 페이지 `public/brand/concepts/index.html`. 각 안은 200×200 규격이며, `mascot.js` 애니메이션 계약 클래스와 동공 좌표, `ydm-` 그라데이션 ID를 포함합니다. `<text>`와 외부 에셋 참조는 쓰지 않았습니다. 비교 페이지는 세 안을 각각 200·64·32·16px로 밝고 어두운 바탕에서 보여줍니다.

- **A · 콩방울 영이** — 새싹 꼭지와 가슴의 작은 책갈피 하트를 가진 물방울. 서비스의 학습·성장을 친근하게 표현합니다. 16px에서는 물방울 실루엣과 눈, 꼭지가 남고 가슴 무늬는 축소 시 사라질 수 있습니다. 기쁨·당황·졸림·눈 가림 표정 모두 가능하며, 기존 손 가리기 이동량에 맞췄습니다.
- **B · 책갈피 요정 북키** — 펼친 책 몸통과 위쪽 책갈피 꼬리. 본문·단어 학습과 직접 연결됩니다. 16px에서는 책의 펼침선과 책갈피 실루엣이 핵심입니다. 공통 눈·입·손 클래스가 있어 표정 변화가 가능합니다.
- **C · 형광펜 요정 하이라잇** — 캡과 클립, 강조 띠가 있는 형광펜 생물. 핵심 표현 표시 기능을 상징합니다. 16px에서는 캡이 달린 펜통 실루엣이 남습니다. 얼굴·손 위치를 기존 64px 눈 가림 동작에 맞춰 표정 변화가 가능합니다.

**추천: A · 콩방울 영이.** 16px에서도 단순한 물방울 외곽과 꼭지·눈 조합이 남을 가능성이 높고, 서비스의 그라데이션과 기존 캐릭터 동작을 자연스럽게 이어갑니다. 책·형광펜보다 흔한 사물 아이콘으로 보일 위험이 낮고 표정이 잘 드러납니다.

정적 확인: SVG 세 파일 XML 파싱, viewBox·필수 클래스·동공 좌표·그라데이션 접두어·외부 참조 금지 확인 완료. **브라우저 시각 검수는 하지 못했습니다**(이 세션에 브라우저 제어 도구가 없어 16px 판독성은 실제 화면에서 확인되지 않음). 다음 단계는 Claude의 시안 선택·수정 지시입니다.

4. 시안 비교 페이지의 16px 칸 — 전신을 그대로 줄이니 판독 불가(점 수준). 파비콘은 별도 크롭이 필수(아래 작업 2).
