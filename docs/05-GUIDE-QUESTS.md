## 결정
- **Q1 서버 판정·한 번만**: 퀘스트 보상은 `QuestClaim{user,key}` 고유 인덱스로 기록 → 같은 보상 두 번 불가(동시 요청도 하나만). 조건 퀘스트(세트 만들기·시험 완주 등)는 서버 기록으로 판정, 조건 전이면 400.
- **Q2 보고형 퀘스트**: 가이드 읽기·학습 카드 끝내기는 서버가 볼 수 없는 활동이라 보고로 인정 — 보상을 작게(+5~+15) 하고 한 번(매일 퀘스트는 하루 한 번)만.
- **Q3 경험치 = 결과 경험치 + 퀘스트 보상**. `learn.js gameOf()` 한 곳에서 홈·결과·퀘스트·프로필이 같은 값을 씀.
- **Q4 업적 id 는 바꾸지 않음**(브라우저의 '이미 본 업적' 기억이 id 기준). 04 의 9개 id 유지 + 26개 추가.
