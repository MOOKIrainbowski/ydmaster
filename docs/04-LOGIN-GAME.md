# 04 로그인 정리 · 마스코트 수정 · 시험 설정 창 · 게임 요소 (2026-11-20, Claude 단독)

## 사용자 지시 요약
1. 로그인 페이지 세로가 길어 스크롤이 생김 → 높이를 줄여 스크롤 제거
2. 입력칸마다 값을 한 번에 지우는 x 버튼
3. 로그인 버튼 아래 작은 체크박스: 이메일(아이디) 저장 · 로그인 유지
4. '비밀번호를 잊으셨나요?' 는 작은 글자 버튼, 옆에 '회원가입' 글자 링크(가입 버튼 디자인 변경)
5. 마스코트의 발 같은 빨강·파랑 타원과 배의 하트 제거
6. 시험 설정 팝업을 더 구체적으로
7. 단어·본문 공부가 지치지 않게 게임 요소·효과로 성취감

### 게임 요소(G 결정)
- **G1 서버 판정**: 경험치·레벨·업적은 저장하지 않고 Result 에서 매번 계산(`server/game.js` 한 곳, `/api/stats` 의 `game`, 결과의 `xp`). 클라이언트는 보여주기만 → 꾸밀 수 없고 규칙을 바꿔도 옛 기록에 그대로 적용. golden 테스트 `test/game.test.js` + API 테스트로 집계식 일치 확인.
- **G2 규칙**: 경험치 = 맞힘×10 + 완주 20 + (5문항 이상 만점) 50. 레벨 n 시작 = 50·n·(n−1). 칭호 새싹→단어 탐험가→문장 사냥꾼→어휘 기사→내신 마법사→영단 마스터. 업적 9개(첫걸음·퍼펙트·만점 수집가·사흘 연속·일주일 불꽃·백 문항 정복·열 번의 도전·세트 장인·레벨 5).
- **G3 시험 중**: 정답마다 +10 XP 떠오름·상단 XP 카운터, 연속 정답 음이 올라가는 효과음, 3·5·10·15·20 콤보 배너, 절반 응원 배너, 효과음 켜기/끄기(브라우저 저장, Web Audio 합성이라 파일 0).
- **G4 결과**: 별 1~3개(50·80·100점), 얻은 경험치 카운트업, 레벨 막대가 이번 경험치만큼 차오름 → 레벨 업 배너, 새 업적 카드. 축하는 방금 끝낸 시험(`?fresh=1`, 읽은 뒤 주소에서 제거)에서 한 번만.
- **G5 학습 카드**: 알아요(더미에서 빠짐·콤보)/다시 볼래요(맨 뒤로), ↑↓ 키, 다 외우면 마스코트 점프·완료 화면.
- **G6 홈**: 히어로에 레벨 막대, 업적 보드(달성/잠김).
