# 14 최근 학습 · 시험/본문 크게 · 내 정보 메뉴 정리 · 마스코트 · 화면 맞춤 (2026-11-21, Claude 단독)

## 사용자 지시
1. 홈 '오늘의 학습' 은 가장 최근에 학습한 세트로
2. 시험 화면의 선지·본문 크게 / 본문 세트 '본문 읽기' 영역 크게
3. 위 메뉴의 '내 정보' 삭제(프로필 버튼과 겹침)
4. 로그인 화면 마스코트 옆 단어 삭제, 마스코트 크게, 기믹·이스터에그 더
5. 실행 중인 화면 크기를 분석해 UI 배치·디자인을 최적화(어떤 모니터에서도)

## 결과 · 결정
- **R1 최근 학습**: `User.recentSet` — 세트를 열거나(`GET /api/sets/:id`) 시험을 시작하면(`POST /api/sessions`) 서버에 기록(기기 상관없이 같음). `/api/stats` 가 `recent` 로 내려주고, 없으면 예전처럼 최근 만든 세트.
- **R2 크기**: 시험 폭 760→880px, 문제 26/40px, 선지 높이 72px·19px, 시험 본문 22px, 순서 카드 18px. 본문 읽기 상자 여백·글자 clamp(19~24px).
- **R3 메뉴**: 위 메뉴에서 '내 정보' 제거, 내 정보 화면에선 프로필 사진 버튼이 강조. 휴대폰 아래 탭은 프로필 버튼이 없어 유지.
- **R4 마스코트**: 단어 카드 제거, 크기 clamp(260~420px)(휴대폰 140px). 추가 기믹: 끌어당기기(늘어났다 튕김), 꾹 누르기(부풀었다 펑), 빠르게 5번(어지러움), 좌우로 문지르기(간지럼), 두 번 누르기(오늘의 단어 읽기), ↑↑↓↓←→←→BA(무지개 모드), 입력칸 밖에서 hello/hi/love/yeongi, 비밀번호 Caps Lock 안내, 로그인 3번 실패 시 비밀번호 찾기 안내, 잠꼬대, 주말 인사, 숨은 단어 4개 순환.
- **R5 화면 맞춤**(`prefs.js screenInfo/applyPrefs`): 창 크기로 휴대폰/태블릿/노트북/데스크톱/큰 모니터·울트라와이드를 판별. 1920×1050 기준으로 더 큰 화면은 같은 비율로 키우고(최대 1.5배, 2560×1440 → 134%), 높이 800 미만 노트북은 92%. 글자 크기 설정과 곱해 `html zoom` 하나로. 울트라와이드는 내용 폭도 넓힘. 창 크기가 바뀌면 다시 계산. 설정 > 화면에 '화면 크기에 자동 맞춤' 토글과 분석 결과 표시.
  - zoom 안에서 vh·vw 가 배율만큼 커지는 문제 → `--vh/--dvh/--vw`(tokens.css, 배율로 나눔)로 교체. 화면 좌표를 쓰는 곳(색종이·+XP 글자·카드 빛·문법 풍선·마스코트 끌기)은 `zoomOf()` 로 나눔. 예전 '글자 크게' 설정에서도 있던 같은 어긋남이 함께 고쳐짐.

확인: `npm test` 52/52, ESLint 0. 1920·2560·3440·1366·모바일에서 배치 측정 0, 최근 학습 세트가 홈에 나오는 것, 2560 에서 문법 풍선 위치, 마스코트 기믹(두 번 누르기·어지러움·비밀 코드·hello·끌기) 동작 확인.
