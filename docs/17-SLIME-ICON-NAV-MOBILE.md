## 확인한 것
- 테스트 56/56, ESLint 0건.
- 헤드리스 Chrome(개발 서버):
  - 로그인 화면 슬라임 영이, 7번 누르면 작은 슬라임 2개 분열(.slime-mini 2개).
  - 데스크톱 위 메뉴 아이콘 줄(가이드 없음, 문의·확성기·친구 있음), 세트 화면 수정·삭제 작은 아이콘.
  - 휴대폰(390px): 아래 탭바 아이콘만, 위 도구 줄 5개, 탭바 흐림 none·오로라 필터 none, 내 메뉴에 친구·공지·문의 없음.
  - 로딩 덮개 z-index 1000, 영이가 글자 위에 보임.

## 확인 못 한 것
- 실제 휴대폰에서 체감 속도(에뮬레이션만 함).
- 세트 화면 오답 복습 버튼은 시험 계정에 오답이 없어 화면으로는 못 봄(코드만).
- 이미 홈 화면에 설치한 앱 아이콘은 지웠다 다시 추가해야 바뀜.

## 17 후속(2026-11-22): 페이지 이동 중 영이가 가려짐
- 원인: 화면 전환(View Transition) 중에는 view-transition-name 이 붙은 #main·메뉴 아이콘·알약이 문서 위 전환 레이어에 그려져 z-index 와 상관없이 로딩 덮개를 덮음. 프로필처럼 데이터를 기다려 로딩 화면이 뜨는 이동에서 보임(휴대폰은 전환을 생략해 해당 없음).
- 수정: 덮개에 view-transition-name: loader + ::view-transition-group(loader) z-index 50(전환 레이어 맨 위). 사라지는 중인 덮개는 이름을 빼 중복 방지.
- 확인: 헤드리스에서 둘러보기→내 프로필 이동을 느리게 재현 — 고치기 전 본문 카드·메뉴가 영이를 덮음, 고친 뒤 영이가 맨 위.
