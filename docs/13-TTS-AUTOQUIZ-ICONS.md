# 13 문장 발음 · 표시 없는 본문 시험 · 아이콘 버튼 (2026-11-21, Claude 단독)

## 사용자 지시
1. 본문 세트에서 문장마다 TTS 발음 듣기
2. 시험 설정의 '어법·어휘 고르기', '핵심 표현 빈칸' 으로 응시할 수 없는 문제 → 본문에 단어(문장)만 입력해도 모든 모드 사용 가능하게
3. 뜻을 그림으로 나타낼 수 있는 버튼은 텍스트 대신 아이콘으로(즐겨찾기→별, 수정→연필, 삭제→휴지통, 검색→돋보기, 시험 보기→재생)

## 원인 (2번)
두 모드는 사용자가 본문에 `{핵심 표현}` · `[정답|오답]` 을 직접 표시한 문장만 출제했다. 표시 없이 문장만 넣은 세트는 후보가 0개라 "표시된 문장이 없습니다" 오류(400)로 시작이 안 됐다.

## 결과
- **문장 발음**: 문장 카드 머리에 스피커 버튼 → 브라우저 TTS(설정의 속도·억양 그대로, 기존 `speak()`).
- **자동 출제** (`server/autoquiz.js`, 화면 문법 풀이와 같은 compromise 엔진):
  - 핵심 표현 빈칸: 구동사 > 형용사+명사 > 본동사 > 명사·-ly 부사 순으로 문장당 1개(14단어 이상이면 2개).
  - 어법·어휘 고르기: 내신 어법 단골(to부정사 vs 동명사, 전치사+동명사, 능동/수동, 수 일치, 동사 자리, who/which, 관계부사, 형용사/부사, 보어 자리 형용사)로 [정답/오답] 생성. 해당 없으면 같은 세트의 같은 품사 단어로 어휘 선택지.
  - 사용자가 표시한 문장은 표시 그대로(자동은 표시 없는 문장만). 문항에 `auto: true`.
- **아이콘 버튼**: 세트(수정·삭제·시험 보기·즐겨찾기(켜지면 노란 별)·복사·공유·발음), 편집기(삭제·추가), 검색(둘러보기·친구·관리자), 공지 수정/삭제, 친구 삭제, 프로필 수정, 설정 '발음 들어보기', 업데이트 새로고침. 모두 `aria-label`(화면읽기) + `title`(마우스 올리면 이름). 뜻이 그림으로 분명하지 않은 버튼(목록 보기, 오답 복습, 답변 저장 등)은 텍스트 유지.

## 결정
- T1 자동 출제는 규칙 기반이라 가끔 어색한 선택지가 나올 수 있음 → 정확히 내고 싶은 문장은 기존처럼 `{ }` · `[정답|오답]` 표시가 우선.
- T2 기존 테스트(표시 없는 문장은 제외)는 새 동작에 맞게 고침, `test/autoquiz.test.js` 추가.

확인: `npm test` 52/52, ESLint 0, 표시 없는 본문으로 6개 모드 세션 생성 201 + 자동 어법 문항 채점 정답 처리, 배치 측정(세트·편집·둘러보기·친구·내 정보·모바일) 0, 문장 발음 버튼 → TTS 호출 확인.
