# 12 본문 문장 카드 · 문법 풀이 (2026-11-21, Claude 단독)

## 사용자 지시
1. 본문 세트를 암기할 때 문장마다 볼 수 있고, 문장 카드 바로 밑에서 해석 보기/숨기기
2. 문장의 단어·문장에 마우스를 올리면 그 요소가 문장에서 하는 역할, 포함된 문법을 설명

## 결과
- **문장 카드**(기본): 번호 · 영어 문장(핵심 표현 강조, 선택지 [A / B]) · 바로 아래 '해석 보기/숨기기'(부드럽게 펼침). 위 막대에 '해석 모두 보기', '본문 읽기'(한 문단으로) 전환.
- **단어 풀이**: 단어에 마우스를 올리면(휴대폰은 누르면 고정) 풍선에 품사 · 문장 성분(주어/서술어/목적어/보어/수식어…) · 동사 원형 · 관련 문법(최대 3개, 문장 속 해당 부분 인용 + 설명). 그 문법에 속한 단어들이 주황색으로 함께 강조.
- **문장 풀이**: 번호에 올리면 문장 형식 · 시제·태 · 절 구조 · 문법 포인트 요약. '문장 분석' 을 켜면 성분 색 밑줄(주어 파랑·서술어 빨강·목적어 초록·보어 보라·수식어 회색)과 문법 포인트 목록(누르면 해당 부분 강조).
- 다루는 문법: 1~5형식, 주어·목적어·보어(간접/직접·목적격 보어), to부정사(명사·형용사·부사적 용법, 진주어, 목적격 보어), 동명사(주어·목적어·전치사의 목적어), 현재분사(앞·뒤 수식), 분사구문, 수동태(by 행위자), 현재·과거완료, 조동사(+have p.p.), 관계대명사·관계부사절(선행사), 명사절(that·that 생략·간접의문문), 부사절(이유·양보·조건·시간), 가정법 과거·과거완료·혼합, 비교급·최상급, 가주어 it, There + be, 4형식 수여동사, 구동사, 명령문, 문두 부사구, 전치사구(형용사·부사 역할).

## 결정
- **G1 무료·즉시**: 유료 AI API 대신 오픈소스 영어 분석기 compromise 14.14.4(MIT, `public/vendor/`, 라이선스 동봉)로 품사를 얻고, 내신 문법 설명은 `public/js/shared/grammar.js` 규칙으로. 키·비용 없음, 본문 세트 화면을 열 때만 불러옴(약 110KB 압축). 화면은 먼저 보이고 분석은 뒤에서 조금씩.
- **G2 정확도**: 자동 분석이라 틀릴 수 있음을 풍선·분석 칸에 표시. golden 테스트(`test/grammar.test.js`)로 대표 문장 20여 개의 형식·성분·문법 포인트를 고정. 더 정확한 해설이 필요하면 AI 해설(유료 API 키 필요)을 추가하는 방안이 있음.
- 예전 본문 한 덩어리 보기·해석 토글은 `passage-study.js` 로 옮김('본문 읽기' 모드).
